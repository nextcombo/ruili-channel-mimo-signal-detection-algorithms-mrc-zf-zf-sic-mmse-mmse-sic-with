# Ruili Channel MIMO Signal Detection Algorithms (MRC, ZF, ZF-SIC, MMSE, MMSE-SIC) [with MATLAB code]

Generally speaking, the more antennas deployed at both the sender and receiver ends, the more possible signal paths there are, leading to higher data rates and better reliability. However, this also brings about increased hardware complexity and signal processing complexity as well as an increase in energy consumption. Some near-ML algorithms that have been widely applied in traditional MIMO systems exhibit excellent detection performance but suffer from high complexity, which is generally considered unsuitable for large-scale MIMO systems. We will analyze and discuss these issues below. Regarding the current research hotspots in the field of large-scale MIMO uplink signal detection algorithms, we will conduct theoretical analysis and simulations on three detection algorithms (Maximum Ratio Combining (MRC), Zero Forcing (ZF), and Minimum Mean Square Error (MMSE)) to determine whether they meet the requirements for detection performance and system performance in large-scale MIMO systems.
In the previous chapter, through theoretical analysis and simulation, we proved that under good propagation conditions, when the number of base station antennas far exceeds the number of users, simple linear signal detection methods can achieve good detection performance. In reality, there are often situations where the number of users is not significantly different from the number of base station antennas, so in recent years, some advanced nonlinear signal detection algorithms such as iterative signal detection algorithms and random step methods have also become research hotspots in the field of large-scale MIMO. Currently, the nonlinear signal detection algorithms suitable for large-scale MIMO systems mainly include serial interference cancellation algorithms (ZF-SIC/MMSE-SIC), Block-iterative Generalized Decision Feedback Equalizer (BI-GDFE) algorithms based on decision feedback, and Tabu Search (TS) algorithms.
Non-linear signal detection algorithms, while achieving higher detection performance, incur the cost of increased computational complexity. The computational complexity is largely determinative of whether an algorithm can be practically applied in large-scale MIMO systems.
